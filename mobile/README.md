# Aplicación Móvil — Flutter

Cliente móvil multiplataforma que consume los mismos endpoints `/api/v1` que el frontend web, agregando geolocalización y mapa interactivo de locales cercanos.

> Se desarrolla a partir de la **Evaluación 2**.

## Inicialización

```bash
flutter create .
flutter pub get
flutter run
```

Ver [docs/01-arquitectura.md](../docs/01-arquitectura.md).
